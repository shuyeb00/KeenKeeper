# KeenKeeper

A personal relationship manager that helps you keep your friendships alive.

## Technologies Used
- **Next.js** (App Router) — Framework
- **Tailwind CSS** + **DaisyUI** — Styling
- **React Icons** — Icon library
- **Recharts** — Analytics charts
- **React Hot Toast** — Notifications

## Key Features
- 📋 Friend profiles with status tracking (On Track / Almost Due / Overdue)
- 📞 Quick check-in logging (Call, Text, Video) with toast feedback
- 📜 Interaction timeline with filter by type
- 📊 Friendship analytics donut chart
